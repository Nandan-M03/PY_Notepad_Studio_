Get started

On a PC

  1. Download and unzip the file.
  2. Double-click index.html.
  3. Stay online the first time so Python can load.

On a phone or tablet

  1. Tap Open in browser.
  2. Use Add to Home Screen or Install app from the browser menu.
  3. After the first launch it works offline.

Files are saved in the browser of the device you use, so use Export ZIP inside the app to back up or move projects.

Good to know

PY Notepad runs Python inside your browser. That means no debugger, Git or system terminal yet, and heavy native libraries such as PyTorch, TensorFlow or Playwright can't run. Run untrusted code with care, as with any code editor.
